## 🚀 GitHub + Vercel 배포 절차

### 사전 준비

> ⚠️ **가장 중요한 한 가지**: HTML 파일명을 반드시 **`index.html`** 로 변경할 것
> Vercel은 `index.html`이라는 이름만 메인 페이지로 인식합니다.

---

### STEP 1 — GitHub 저장소 생성

1. [github.com](https://github.com) 로그인
2. 좌측 상단 **"New"** 버튼 또는 우측 상단 **`+` → "New repository"** 클릭
3. 설정 입력:

   | 항목 | 값 |
   |---|---|
   | Repository name | `community-resource-portal` (영문·하이픈) |
   | Visibility | **Public** |
   | Add a README file | ✅ 체크 |
   | 나머지 | 기본값 유지 |

4. **"Create repository"** 클릭

---

### STEP 2 — HTML 파일 업로드

1. 저장소 페이지에서 **"Add file" → "Upload files"** 클릭
2. `index.html` 파일 드래그&드롭
3. 하단 **"Commit changes"** 클릭

> ✅ 저장소에 `index.html` 이 보이면 완료

---

### STEP 3 — Vercel 연결 및 배포

1. [vercel.com](https://vercel.com) 로그인
2. **"Add New..." → "Project"** 클릭
3. 저장소 목록에서 `community-resource-portal` → **"Import"** 클릭
4. 설정 화면에서 **아무것도 건드리지 말 것**:

   | 항목 | 처리 |
   |---|---|
   | Framework Preset | Other (자동) |
   | Build Command | **빈칸 유지** |
   | Output Directory | **빈칸 유지** |
   | Environment Variables | **빈칸 유지** |

   > 단일 HTML 파일은 빌드 과정이 없어 설정이 필요 없습니다.

5. **"Deploy"** 클릭 → 30초~1분 대기

---

### STEP 4 — 배포 URL 확인

- 완료 후 Vercel 대시보드에서 배포 URL 확인
- 형식: `community-resource-portal-xxx.vercel.app`
- 외부망(휴대폰 데이터 등)에서 접속하여 정상 작동 확인

---

## 🔄 앞으로 수정하는 방법

### 방법 A — 작은 수정 (GitHub 웹에서 직접)

1. GitHub → 저장소 → `index.html` 클릭
2. 우상단 **✏️ 연필 아이콘** 클릭
3. 웹에서 직접 편집
4. **"Commit changes"** 클릭
5. ✨ Vercel이 **자동으로 1분 안에 재배포**

### 방법 B — 큰 수정 (새 버전 파일 교체)

1. 새 HTML 파일을 **`index.html`** 로 이름 변경 ← 필수!
2. GitHub → 저장소 → **"Add file" → "Upload files"**
3. 새 `index.html` 드래그&드롭 → **"Commit changes"**
4. ✨ 자동 재배포

## 🛠️ 트러블슈팅

| 증상 | 원인 | 해결 |
|---|---|---|
| 배포 후 빈 화면 | 파일명이 `index.html`이 아님 | GitHub에서 파일명 수정 후 Commit |
| 저장소가 Vercel에 안 보임 | 권한 누락 | Vercel → Settings → Git → "Manage GitHub App Installation" → 저장소 권한 추가 |
| 수정했는데 변경 안 됨 | 브라우저 캐시 | Ctrl+Shift+R (강력 새로고침) |
| Build Failed 오류 | Build Command에 뭔가 입력됨 | Vercel 프로젝트 → Settings → Build Command 비워두기 |
